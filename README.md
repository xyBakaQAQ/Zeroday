一个 **Minecraft 26.2** 的 Fabric 客户端模组,使用 **Java 25**、**Mojang 官方映射**,并以 **Skija(Skia 的 Java 绑定)** 渲染。

---

## 🔨 构建

需要 **JDK 25**。

```bash
./gradlew build
```
